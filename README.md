The Split Bill Web Application is a simple and practical tool designed to make everyday life easier. 
It helps roommates quickly and fairly calculate shared expenses, so you can spend more time enjoying life together instead of arguing over bills.
The application provides clear and user-friendly input fields for:
- Number of roommates
- Rent cost
- Electricity bill
- Wi-Fi bill
- Optional savings contribution

Users can also choose a savings percentage (for example 10%, 15%, or none), which is especially useful if roommates are planning to save for future purchases or apartment upgrades.
After filling in all required fields, the user simply clicks Submit, and the application instantly calculates and displays:
- The total amount
- The cost per person for each bill

This project is built using JavaScript, with CSS used to style the user interface.
One of the main challenges in this project was implementing the necessary JavaScript logic to handle calculations and user input correctly.
This experience helped strengthen my understanding of JavaScript methods and real-world problem solving. 
I plan to expand and improve these features in future projects.

No additional setup is required — simply open the application and start using it.
